## 配音踩点三件事

1. **一句一场景**：每句台词对应一幕画面，别合并也别拆开，时间点才对得上。
2. **语速**：表格按 4.6 字/秒算。剪映默认音色偏慢，选「知识 / 新闻」类或调快到 1.1~1.2x。
3. **英文词**：`Wednesday`、`library` 读得别扭就换成说法「星期三这个词」「图书馆」，
   原文全文见 `docs/短视频口播文案.txt`。

## 要重算 / 要调整

- **改台词**：改 `scripts/gen-video-narration.py` 的 LINES → `node scripts/patch-video-lines.js`
  重新写入页面 → 再跑本脚本。
- **改节奏**：页面里的 `var RATE=4.6;`（越大越快）与本脚本同名常量需同步修改。
