# 竞品分析与建议（2026-10-08）

> 面向「功课抽查」当前定位：小学生英语单词，**家长/老师布置 → 孩子真练 → 结果被第三方看见**。
> 本文只回答两件事：**市面上的钱和人是怎么分布的**，以及**在这个格局里我们该做什么、明确不做什么**。
> 所有数据都标了来源与可信度，软文数据单独标注 —— 结论不建立在软文数字上。

---

## 一、一句话结论

**不要正面打"背单词体验"，那已经是红海且巨头在用 AI 把内容成本压到接近零。**
我们的位置在另一条轴上：**"第三方派发 + 结构化作答 + 结果可核验"**。
这条轴上，B 端校产品（天学网、翼课网）太重太慢，小程序同行（蜜蜂家校一类）做的是"家校沟通 + 拍照批改"，
**把英语词汇真正做到"练到位"（发音 + 拼写 + 听写 + 字母级诊断）的很少** —— 缝隙就在这里。

一句话产品定位建议：**校内教材同步的"听写默写练习 + 自动判分 + 老师/家长可见"，而不是"又一个背单词 App"。**

## 二、竞品地图：四层

| 层 | 代表 | 核心打法 | 对我们的意义 |
|---|---|---|---|
| 全球巨头 | Duolingo | 游戏化 + AI 口语 + AI 批量产内容 | 看趋势风向，**不做它的对手** |
| 国内垂类头部 | 百词斩、墨墨、不背单词、扇贝 | 各自的记忆法/语境/算法，C 端自学 + 考级应试 | 体验与词库打不过，**不进它的赛道** |
| K12 校内同步新势力 | 背单词花园、星空外语、可栗口语、天学网、翼课网、腾讯英语君 | 教材版本覆盖 + AI 口语/纠音 + 家长端/校端 | 卖点方向要学，**这是我们的直接参照系** |
| 小程序小同行 | 蜜蜂家校、柏思背单词、各类"XX 背单词打卡" | 免费 + 微信内即用 + 拍照批改/打卡 | **最贴身的对手**，要逐条对标 |

## 三、关键事实（带可信度）

### 3.1 Duolingo（高可信：SEC 8-K / 财报电话会）

- 规模：2026 Q2 DAU **5870 万**（同比 +23%），付费用户 1250 万；FY2025 bookings 约 11.58 亿美元。
- 战略转向（2026）：**明确"用户增长优先、变现第二"**，主动放弃 **5000 万美元以上** bookings 来降低免费用户的摩擦（减广告、减 upsell）。目标 2028 年 1 亿 DAU。
- AI 内容产能：2026 Q1 单季发布 **20,500 个课程单元**（2025 年是每季 7,100，2024 年是 1,800）。
- AI 成本：Video Call 单次成本从约 **$0.30 降到 <$0.01**（换开源模型），口语能力正在被大规模下放给免费用户。
- 产品动作：**用"说"替代"打字"**（spoken tokens：大部分题目用嘴答而不是点选/键入）、单元末加"掌握度检测"（没掌握不许往前走）。

**对我们的两条启示：**
1. **巨头正在主动弱化"拼写输入"** —— 因为对成人兴趣学习者，打字是摩擦；但**校内考试场景里拼写是硬刚需**。这块被让出来的地，正是我们的主战场。
2. **AI 让内容成本趋零，但没让"关系链"和"责任闭环"变便宜**。家长愿意为"知道孩子练没练"，老师愿意为"不用自己出题判卷"付费 —— 这是 AI 替代不了的。

### 3.2 国内垂类头部（中可信：用户体感帖/测评，非官方数据）

| 产品 | 用户公认的长处 | 用户公认的短板 | 对我们的意义 |
|---|---|---|---|
| 百词斩 | 图背门槛低、社交/打卡氛围好 | 改版动了学习流程引发老用户流失；广告密；高阶词"记图忘词" | 老用户因"习惯被改"流失 —— **我们改流程要发公告+保留旧路径** |
| 墨墨 | 抗遗忘算法口碑最强、复盘高效 | 免费词量上限（付费墙硬）、界面被吐槽 | 算法是标配，不是卖点；**免费额度别卡太死** |
| 不背单词 | 影视原声语境、体验干净无广告 | **免费用户拼写测试每天仅 3 次**；"适合复习不适合新学" | 拼写被当成付费点限制 —— 我们把它当主流程是差异化 |
| 扇贝 | 功能最全（拼写/听写/词文串学）、多端 | 流程重、单轮耗时长、趣味不足 | 全而重，**我们做"每天 10 分钟练完就走"** |

一条高频吐槽值得记住：**"一天不复习，第二天欠几百个词，利滚利"**（不背/万词王）。
→ 我们的任务量必须**有上限、可清零**，否则家长第一次打开就被吓跑。

### 3.3 K12 / 小程序同行（中低可信，部分是投放软文）

**明确提示**：网上"背单词花园""星空外语 SkyLingo""可栗口语"的横评稿，句式和数据高度雷同（85 个教材版本、150 万日活、KET 通过率 +25%），属于投放软文，**数字不可信**。但它们反复强调的**卖点方向是真的**，值得抄作业：

- **教材同步到"版本 → 册 → 单元"**：所有 K12 产品的第一卖点，家长认这个。
- **家长端看报告、设每日新词量**：家长焦虑的出口。
- **AI 跟读打分 / 音素级纠音**：2026 年的标配宣传点。
- **微信内即用、无广告、不下载**：小程序形态对小学生是刚需（家长不愿给孩子装 App）。

对标更值得认真看的两家：

| 同行 | 做什么 | 做得到位的地方 | 没做到位的地方（我们的机会） |
|---|---|---|---|
| **蜜蜂家校**（原蜜蜂作业） | 家校沟通 + 作业布置 + 拍照 AI 批改 + 课本同步跟读/听写 + 班级错题本 + 学情报告，承诺教师永久免费 | 免费 + 微信生态 + 老师工作流完整 | **英语词汇的练习本身很浅**：跟读/听写靠拍照上传，判分粒度粗（对/错），拿不到"哪个字母错、哪个音没发准"，也无法做针对性巩固 |
| **柏思背单词**（小程序） | 认读 / 听写 / 拼写 / 生词本，教材册级词书 | 轻、免费、形态对 | **明确写了"没有单独的老师后台看全班"** —— 派发与统计这一层是空的 |
| 腾讯英语君 / 天学网 / 翼课网 | 校端作业、同步教材、AI 批改 | 合规（备案/等保）、进校渠道、题库 | 重（学校采购、老师培训），**个人与家庭用户进不去** |

**结论**：小程序同行占据了"免费 + 微信内 + 老师用得起"，但**练习深度**和**结构化判分**是空白；
校端产品占据了"合规 + 渠道"，但**家庭/个人场景进不去**。
我们卡在中间：**练习做得比小程序同行深，门槛比校端产品低**。

## 四、我们真实的牌（不吹不黑）

**已经拿在手里的、竞品不便宜就能抄的：**

1. **「认 → 写 → 巩固」+ 抄写的真闭环**：不是选义就算会了，必须拼出来；错词当场回炉，答对才出列。
   市面主流把"拼写"当附加项甚至付费项（不背免费 3 次/天），我们把它放主流程。
2. **结构化作答带来的字母级判分**：知道"第 3 个字母应该是 t，写成了 f"。
   拍照批改（蜜蜂家校）永远拿不到这个粒度，**这是我们最硬的数据资产**。
3. **本地发音 400 词全量离线可用**（Piper 批量生成 mp3 + 分包）：不依赖在线 TTS，弱网/飞行模式也能听写；成本是零边际的（一次生成）。
4. **作业派发 + 完成度口径 + 学习简报**：老师/家长那一端已经能看见"谁没做、错在哪、用了多久"。
5. **榜单/荣誉 + 分享**：天然适合微信裂变（家长晒娃、班级比拼）。

**明显是短板的（要承认）：**

- 词库体量与教材覆盖：目前是 400 词 + 外研四上一册，**离"全国几十个版本 × 各册 × 各单元"差两个数量级**。
- 没有 AI 口语评测（2026 年 K12 产品的标配宣传点）。
- 个人主体的硬限制：**不能开微信支付**（收不了钱）、教育类目与资质受限。
- 没有运营与内容产能（Duolingo 单季 2 万单元，我们靠手工录词表）。

## 五、建议（按优先级）

### P0 · 加固护城河（1–2 周，且必须做在前）

**1. 词库升级为"版本 → 册 → 单元"三级结构**
- 理由：K12 赛道的第一卖点就是教材同步，家长判断"这个能不能用"只看这一条。现在"外研三起四上"是一整册摊平，老师布置"Unit 3"是核心动作。
- 代价：词表整理是纯人力（OCR 教材词表 + 人工校对）。**只做单词与中文释义，不要扫描教材插图**（版权风险集中在图片与版式，词表本身风险低）。
- 验收：老师能选"外研三起 · 四上 · Unit 3"一键布置，词序与课本一致。

**2. 老师端做成"一张表"：谁没交、谁错得多、错哪些词**
- 理由：行业口径里英语老师每周 11 小时以上耗在作业布置与机械批改（该数字来自投稿文，未标注来源，仅作方向参考）。老师要的不是图表，是**一行一个学生的表 + 错词 TOP**。
- 落地：`class` 云函数已有 `summary` / `per_student`，补"班级高频错词 + 高频错字母组合"两个字段，前端用表格直接呈现。
- 验收：老师打开 5 秒内知道今天该找哪 3 个学生、该重讲哪 5 个词。

**3. 家长端"今日简报"可订阅、可分享**
- 理由：简报文案已经有了（"经过 X 分钟学了 N 个词…"），但只出现在孩子手机里。家长是付费方，简报要能到家长手上。
- 落地：分享卡片（已有 `onShareAppMessage`）+ 订阅消息（只做服务通知，不做邀请，符合现有合规结论）。
- 验收：家长在自己微信里能看到孩子当天的完成情况，不需要问孩子。

### P1 · 拉开体验差距（1–2 月）

**4. 把"字母级诊断"做成班级级资产**
- 我们独有的数据：哪个词错得最多、错在哪个字母、是不是同一类（双写字母、-oo-、-tion）。拍照批改产品永远拿不到。
- 落地：错题本增加"错因归类"，班级页增加"本周高频错词 TOP5 / 易错拼写模式"。
- 验收：老师能说"我们班 -oo- 这类词普遍错"，而不是只知道"小明的正确率 70%"。

**5. 听写单导出 / 播放清单（纸质场景的补位）**
- 家长最常做的真实动作是**纸质听写**。我们提供"生成本单元听写单（可打印）+ 按顺序播放发音"，把线下场景接进来。
- 落地：一个页面 + `tts` 顺序播放；打印用"复制文本/分享到文件传输助手"即可，不必真做 PDF。

**6. 发音扩到全教材词 + 解决包体**
- 分包已 1.81MB（红线 2MB），继续加 mp3 会撞线。方案：按册拆多个分包，或改**云存储按需下载 + 本地缓存**（云开发存储直出 https，免域名备案）。
- 落地顺序：先按册分包（改动小），量再上去再迁云存储。

**7. 游戏化要克制：只做"坚持记录"**
- 做：连续打卡天数、家长可见的坚持曲线、班级内的完成度排名（已有）。
- 不做：抽卡、养成、虚拟货币。K12 场景下家长会认为"这是在骗孩子玩"，且和"校内提分"的目标冲突。

### P2 · 验证后再投（先别做）

**8. AI 跟读打分**
- 2026 年已是标配宣传点，成本也在快速下降（Duolingo Video Call 单次 <$0.01）。但对我们：需要录音上传、评分 API、存储与合规（儿童语音数据），且**个人主体审核风险高**。
- 建议先用零成本方案验证需求：**跟读录音 → 回放给孩子自己听 / 发给家长听**，看有多少人真的用。有人用再上自动打分。

**9. 商业化**
- 硬约束：个人主体**开不了微信支付**。路径是先升级主体（个体工商户/公司），再按"教练席位订阅"收钱（`docs/角色体系与商业模式.md` 已定）。
- 定价参照：扇贝大会员年费 200+（二手口径），校端产品走学校采购。**我们的收费对象是老师/机构，不是学生**（学生端继续免费，它是漏斗顶部）。

## 六、明确不做（防止好心办坏事）

| 不做 | 理由 |
|---|---|
| 通用考级词库（四六级/考研/雅思） | 百词斩/墨墨/扇贝已占死，且偏离校内场景 |
| 拍照批改、全科作业 | 蜜蜂家校/作业帮已占，重运营重审核，与个人开发者不匹配 |
| AI 聊天外教 | 同质化 + 成本 + 合规三重风险，且不是我们的差异化 |
| 重游戏化（抽卡/养成/虚拟币） | 与"校内提分"目标冲突，家长第一眼就会否定 |
| 与 Duolingo 拼内容产能 | 单季 2 万课程单元，个人开发者没有任何胜算 |

## 七、风险清单

1. **主体与资质**：个人主体不能开支付、教育类目受限。商业化前提是先升级主体 —— 这件事周期长，**现在就该启动**。
2. **版权**：词表（单词 + 释义）风险低；**教材插图、扫描件、原书音频**不可碰。
3. **未成年人隐私**：涉及儿童学习数据，隐私协议与数据最小化要做在前面（只存 openid + 学习状态，不收集姓名学校）。
4. **包体红线**：分包 1.81MB，扩词库/音频前先算体积（`npm run check` 已带分包体积校验）。
5. **改流程的流失风险**：百词斩因改版动学习流程导致老用户流失（用户体感帖）。我们每次动主流程，要**公告 + 保留旧路径一个版本**。

## 八、建议盯的四个数

| 指标 | 为什么 | 目标（先拍，待验证） |
|---|---|---|
| 学员次日留存 | 练习本身有没有价值的最诚实信号 | ≥ 35% |
| 作业当日完成率 | 派发闭环是否成立（老师布置 → 学生做） | ≥ 60% |
| 老师次周复布置率 | 老师端是不是真省事（最重要的商业化前哨） | ≥ 50% |
| 家长绑定率（学生邀请 → 家长绑定） | 变现链路的转化率 | ≥ 20% |

**北极星建议：老师次周复布置率。** 它同时验证了"练习有效""统计有用""值得付费"三件事，
比 DAU 更能预测这门生意成不成立。

## 九、与现有路线文档的衔接

`docs/开发与运营路线.md` 里"阶段 3 教练端必须等阶段 2 数据说话"的判断**依然成立**，
但竞品格局给出一个补充：**小程序同行已经在做派发与统计（蜜蜂家校免费、柏思明确不做老师端）**，
窗口不会等太久。建议把"教材三级结构 + 老师端那张表"提前到与内测并行 ——
因为**老师是否愿意用，本身就是最强的需求验证**，比学生的留存数据更早给出信号。
