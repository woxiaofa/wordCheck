功课抽查 · 短视频口播文案（剪映 AI 配音直接粘贴版）
生成日期：2026-10-13   |   配套分镜见 docs/短视频宣传-7天脚本.md

【怎么用】
1. 只复制每条下面的「口播正文」部分（标题、画面提示不要复制进去，剪映会读出来）。
2. 剪映 → 文本 → 新建文本 → 粘贴 → 文本朗读 → 挑音色。
3. 建议逐句配音（一句一个文本块），方便跟画面对齐；整段粘也行，节奏由剪映控制。
4. 语速 1.1~1.2x，音量比 BGM 高 6~8 dB。
5. 配完音用剪映「识别字幕」自动生成字幕，比手写快。

【音色建议】
- 家长视角（D1/D6）：亲切女声 / 温柔妈妈音
- 老师视角（D2/D5）：知性女声，语速稍快，干脆
- 观点型（D3）：播报感男声或沉稳女声，压低音量更权威

【⚠️ TTS 读英文的坑】
D1、D6 里有 Wednesday / library 这样的英文词。如果剪映音色读英文发怪音，
按下面括号里的中文替换：
  "Wednesday" → "星期三这个词"
  "library"   → "图书馆这个词"

D1 · 会认 ≠ 会写（约 30 秒）
钩子：你家孩子背得滚瓜烂熟，一听写就废
画面：孩子看手机 → 手敲键盘 → 拼写题打叉 → 报告页 → 妈妈点头 → 结尾卡

【口播正文】
你家孩子是不是也这样：单词背得滚瓜烂熟，一听写就废？
认识，不代表写得出来。
所以我没让他背，我让他写。只给中文，一个字母一个字母敲。
写错了不用我记，它自己进错词本，明天再考一遍。
一天十个词，两分钟，我只看这张表。
背单词最怕的不是记不住，是以为记住了。
想试的，评论区回一，我把词库发你。

D2 · 四十本听写，38 分钟 → 30 秒（约 32 秒）
钩子：四十个孩子的单词听写，你改多久？
画面：班级页长截图（记得遮邀请码）→ 布置作业 → 实时结果 → 催办 → 结尾卡

【口播正文】
四十个孩子的单词听写，你改多久？
我以前三十八分钟。
现在我只做一件事：选单元，点布置。
孩子自己写完，这边实时出结果：谁对、谁错、错哪个词。
没交的直接催，家长点开就是作业，不用我解释第二遍。
三十八分钟，变三十秒。
带班的评论区回作业，我拉你进体验群。

D3 · 别让孩子背单词，让他被抽查（约 34 秒）
钩子：别让孩子背单词（反常识开头，最容易转述）
画面：口播为主 + 三种题型轮播 + 错词本

【口播正文】
别让孩子背单词。
让他被抽查。
背是主动回忆，孩子会自己骗自己。抽查是被动提取，会就是会，不会当场现形。
选义、拼写、听写，三种题型轮着来，专治看着眼熟。
错一个字母就是错，别跟我说差一点。
错的词它替我记着，明天、后天继续考，考到会为止。
同款在评论区，回抽查我发你。

D4 · 情景图填句子（约 28 秒）
钩子：给中文、给图，把句子补完整
画面：demo 页情景填空（图 + 挖空 + 键盘 + 绿勾/红叉）

【口播正文】
这种题你刷到过吧？给中文、给图，把句子补完整。
看着简单，孩子一写就露馅。
我把它做进去了：图在下，句子在上，空出来的词自己敲。
填完点确认，读一遍，对是绿勾，错就当场标红。
从背单词，变成会用单词。
想要这种题型的，评论区回句子。

D5 · 一次设定，四天自动布置（约 30 秒）
钩子：四十二个词，我不会一天全丢给孩子
画面：班级页 → 打开自动布置开关 → 选 4 天 → 计划卡 → 报告页催办

【口播正文】
第二单元一共四十二个词，我不会一天全丢给孩子。
选单元，打开分几天自动布置，选四天。
今天这份当场发出，剩下三天，每天早上八点自动发。
我一周只需要点一次。
布置完我就只看报告，谁没交，点一下催办。
带班的回作业，我拉你进体验群。

D6 · 家长视角看报告（约 28 秒）
钩子：早上送完孩子，我先看的不是群消息
画面：妈妈看手机 → 报告页（10 词/对 7 错 3）→ 错词本 → 结尾卡

【口播正文】
早上送完孩子，我先看的不是群消息，是这张表。
昨天十个词，写对七个，错三个。
Wednesday 错两次，library 错一次。
不用问孩子你背了吗。他还没开口，我已经知道了。
错的词它替我记着，明天继续考。
想看的回报告。

D7 · 一周数据汇报（约 30 秒）
钩子：这一周我发了六条视频
⚠️ 占位数据发之前必须改成真实数字（后台用户数、试用班级数）
画面：数据截图 → 反馈截图 → 下步计划 → 结尾卡

【口播正文】
这一周，我发了六条视频。
后台多了几十个家长、几个班在试用。
反馈最多的一句是：能不能加上我们学校的教材。
所以下一步我就做一件事：拍照上传课本词表，自动生成词库。
还没做好的我不吹，做完再发给你看。
想跟的评论区回一。
