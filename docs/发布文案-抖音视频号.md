## 一、先看清两个平台的差别（决定主战场）

| | 抖音 | 视频号 |
|---|---|---|
| 流量来源 | 算法推荐，陌生人为主 | **社交推荐（朋友点赞扩散）+ 算法**，熟人链为主 |
| 能不能挂我们的小程序 | ❌ **不行**，抖音只认字节系 | ✅ **可以**（微信生态闭环，需先在公众号后台「设置 → 第三方设置 → 小程序管理」关联视频号，再去视频号助手「设置 → 服务菜单」看是否有「跳转小程序」入口；**个人主体是否开放以后台实际显示为准**） |
| 私域引导 | ⚠️ 严格，写“加微信/进群”容易限流 | 相对宽松，可引导关注公众号、加企业微信 |
| 内容调性 | 快节奏、强冲突、前 3 秒定生死 | 真实感、可转发给家长群的内容更容易起 |

**结论：视频号是主战场**——家长刷到后能一键进小程序，转化路径最短，且朋友点赞能穿透家长群。
抖音做增量流量，但只能把人引到评论区，再靠主页/私信转化。

## 四、发布时间

- **主发：19:30~21:30**（家长刷手机高峰，两个平台通用）
- 备选 A/B：早 7:30~8:30（送完孩子的空档）
- 频率：**一天一条，7 天不断**比一天三条然后停更重要
- 视频号额外一步：发完立刻**转发到 2~3 个家长群/朋友圈**——社交推荐是视频号的主要分发方式，冷启动就靠这一步

## 五、合规红线（别踩）

1. **抖音别写"加微信""进群""私信我领"** —— 会被判诱导私域而限流。改成引导评论（"评论区说年级"）。
2. **两个平台都别承诺效果**：不要出现"提分""保证记住""最有效"。我们讲的是方法和工具，不是结果。
3. **K12 学科类内容审核偏严**：文案里不出现"培训""课程""辅导班"，保持"工具/学习方法"口径（和小程序备案时的口径一致）。
4. **D7 的占位数字必须换成真的** —— 这条是真实感最高的一条，编数字反而毁所有。
