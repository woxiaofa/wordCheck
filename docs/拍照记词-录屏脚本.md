# 拍照记词 · 真机录屏脚本（v1，2026-10-22）

> 用途：微信贴图话题 / 朋友圈 / 视频号 / 抖音，主推「拍一张课本词表 → 自动认词 → 直接开背」。
> 成片 **40 秒竖屏**（1080×1920），你只负责**录一条完整流程**，剪辑、字幕、配音我来做。

---

## 一、录制前 5 分钟准备（照着打勾）

- [ ] 手机更新到体验版 **1.1.35**，**关掉调试**（右上角「···」→ 关闭开发调试，左上角 vConsole 绿球要消失）
- [ ] **勿扰模式打开**（避免微信消息弹窗入镜）
- [ ] 相册里准备一张**清晰词表照片**（课本一页、中英文对齐、不反光；建议横着拍满屏）
  - 用相册选图，别现场拍 —— 现场拍光线不稳、要重录
- [ ] 清掉之前的痕迹：首页把当前词库切回「外研四上」，导入页把旧草稿删干净
  - **画面里不能出现真实姓名、班级、学员列表**
- [ ] 屏幕亮度调到 70% 以上（录屏在手机上容易偏暗）
- [ ] iOS：控制中心 → 屏幕录制（长按可开麦克风，**这次不用开**，配音后期做）
  - 安卓：自带录屏，1080P、关闭「显示触摸操作」

## 二、分镜表（一条录完，不要中途停）

| # | 画面 | 你要做的操作 | 后期字幕 / 口播 |
|---|---|---|---|
| 0 | 大字卡（我做） | — | 课本词表 40 个词，抄一遍半小时 |
| 1 | 首页 | 点 **「➕ 添加词库（粘贴 / 表格导入）」**，停 1 秒 | 现在拍一张就行 |
| 2 | 导入页「拍照记词」 | 点 **「拍一张 / 从相册选」** → 选相册里那张词表 → 停 1 秒 | 对着词表拍一张 |
| 3 | 识别中 | 让它跑完（**3~8 秒全保留**，别切走） | 它自己认，几秒钟 |
| 4 | 词表列表 | 从上往下滑一遍（滑慢点）→ 点一个中文格，把认错的改成正确中文（如「动物园」）→ 停 1 秒 | 中文认不准？点一下就能改 |
| 5 | 列表底部 | 点 **「存成我的词库（N）」** → 弹窗 → 点 **「存好就背」** | 存好，两分钟 |
| 6 | 首页 | 等它自动跳回首页 → 停 2 秒（让「词库：照片词表 xx · N 个词」和任务数入镜） | 词库已经是你的了 |
| 7 | 背词页 | 点主按钮进背词 → 出现单词卡（如 panda）+ 点喇叭发音 → 停 2 秒 | 直接开背 |

**节奏要求**：每个动作做完停 **0.8~1 秒** 再点下一个 —— 剪辑留余量，太赶会显得慌。

## 三、可选的加分素材（有就录，没有也能成片）

1. **真人手部俯拍 5 秒**：把课本摊桌上，手指点着词表一行行划（手机俯拍，不用拍脸）
2. **拍照快门的那一下**：用手机原生相机拍词表时的快门声（后期可叠在第 2 镜）
3. **孩子念单词 3 秒**：背词页点发音后孩子跟读（只录声音，后期做画外音）

## 四、录完怎么给我

- 录屏原片（.mp4 / .mov）放到桌面或任意目录，**告诉我完整路径**即可（文件几十 MB 直接发对话容易失败）
- 有多段就都放同一目录，按顺序告诉我文件名

## 五、我拿到后做什么

| 步骤 | 产出 |
