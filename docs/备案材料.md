## 一、身份证照片（最容易驳回的一步）

**官方要求**（微信开放文档《小程序备案材料示例》）：

| 项 | 要求 |
|---|---|
| 格式 | JPG / JPEG / PNG（HEIC 不收；iPhone 用户微信发"原图"即 JPG） |
| 大小 | ≤ 2M；建议压到 300~600K，防止上传后被系统二次压缩变糊 |
| 分辨率 | ≥ 720×1280 |
| 内容 | 原件拍照或彩色扫描、含完整边框、四周圆角清晰、彩色、在有效期内 |
| 禁止 | 复印件、黑白扫描、翻拍屏幕、电子证件、模糊、缺角 |
| 水印 | 可选；加的话只能在空白处、不遮挡文字，内容与备案相关，**不得写有效期** |
| 有效期 | 距提交日 > 3 个月（宁夏 > 6 个月） |

**⚠️ 两个实测坑（官方社区确认过）：**

1. **人像面算「正面」，国徽面算「反面」** —— 与常识相反。传反了会报
   "输入信息与图片信息不符"，白白多跑一轮。
2. 拍照要求四角完整 —— 别裁太紧，桌子背景干净、证件平放垂直拍。

**处理脚本已备好**（压缩到合规大小 + 可选合规水印，输出到 `Documents/备案材料/`，不会进 git）：

```bash
# 不加水印（官方不强制）
python scripts/id-photo-for-beian.py 身份证人像面.jpg 身份证国徽面.jpg

# 想加水印的话
python scripts/id-photo-for-beian.py 人像面.jpg 国徽面.jpg --watermark 仅供小程序备案使用
```

## 四、流程与时效

1. 后台提交 → 平台初审（约 1~2 个工作日）
2. 工信部短信核验（24h 内完成）
3. 管局审核（各省 1~20 个工作日不等，多数 1~2 周）
4. 通过后备案号会自动挂到小程序"关于"页 —— **提审时如果备案还没下来，先别提**，代码里 `docs/上线检查清单.md` 的备案项要等这个号

**总节奏建议**：今天提交备案 → 等管局期间照常发视频 → 备案下来再提审小程序 → 双通过即正式上线。
