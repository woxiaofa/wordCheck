## 一、身份证照片（最容易驳回的一步）

**官方要求**（微信开放文档《小程序备案材料示例》）：

| 项 | 要求 |
|---|---|
| 格式 | JPG / JPEG / PNG（HEIC 不收；iPhone 用户微信发"原图"即 JPG） |
| 大小 | ≤ 2M；建议压到 300~600K，防止上传后被系统二次压缩变糊 |
| 分辨率 | ≥ 720×1280 |
| 内容 | 原件拍照或彩色扫描、含完整边框、四周圆角清晰、彩色、在有效期内 |
| 禁止 | 复印件、黑白扫描、翻拍屏幕、电子证件、模糊、缺角 |
| 水印 | 可选；加的话只能在空白处、不遮挡文字，内容与备案相关，**不得写有效期** |
| 有效期 | 距提交日 > 3 个月（宁夏 > 6 个月） |

**⚠️ 两个实测坑（官方社区确认过）：**

1. **人像面算「正面」，国徽面算「反面」** —— 与常识相反。传反了会报
   "输入信息与图片信息不符"，白白多跑一轮。
2. 拍照要求四角完整 —— 别裁太紧，桌子背景干净、证件平放垂直拍。

**处理脚本已备好**（压缩到合规大小 + 可选合规水印，输出到 `Documents/备案材料/`，不会进 git）：

```bash
# 不加水印（官方不强制）
python scripts/id-photo-for-beian.py 身份证人像面.jpg 身份证国徽面.jpg

# 想加水印的话
python scripts/id-photo-for-beian.py 人像面.jpg 国徽面.jpg --watermark 仅供小程序备案使用
```

## 二、要提前准备的联系方式（别临时找）

| 项 | 要求 |
|---|---|
| 负责人手机号 | 本人实名、**从未给其他备案用过**；备案期间保持畅通，接平台/管局核实电话 |
| 应急手机号 | 必须是**除本人以外**的人的号，同样没用过、不重复 |
| 邮箱 | 本人邮箱，未给其他备案用过 |
| 短信核验 | 收到工信部核验短信后 **24 小时内**完成验证，超时作废 |

### 手机号/邮箱被前公司备案占用了怎么办

规则是硬的：**同一手机号/邮箱只能被一个负责人独占使用**，不同主体之间不可共用；
即使前公司的那个小程序已冻结，历史绑定记录仍会保留。所以确实可能冲突。

按这个顺序走，别一上来就去办新卡：

1. **先直接填现号提交**（几分钟）。驳回话术会是「主体负责人联系方式与已有主体 ×× 重复」——
   没提示就说明没冲突，"好像用过"多半是记错了。
2. **真冲突 → 打 400-670-0700**（微信备案客服），让他们查具体是哪个主体占用的。
   有时对方主体已注销/主体已变更，是可以走的。
3. **仍不行 → 补证明材料**：在「小程序补充材料」处上传**手机号实名注册信息**
   （运营商 App 里可开），并在备注说明"该号码为本人实名，曾用于前公司备案，本人现已离职"。
   这条在部分接入商侧可行，微信侧不保证，属于争取项。
4. **最稳的兜底**：办一张本人实名的新卡（移动/联通/电信最低档保号套餐，月租几元；
   **别用 170/171 虚拟运营商号段**，部分管局不认）→ 同步改小程序管理员手机号
   （mp 后台 → 设置 → 成员管理 → 管理员 → 修改，需原管理员身份证 + 扫码验证。
   **备案负责人必须与小程序管理员一致**，只改备案不改管理员会审核失败）→ 重新提交。

⚠️ **邮箱同样适用这套规则**，如果前公司备案也用的你现在这个邮箱，会一起冲突——
建议提前换一个没用过的邮箱（比如新注册一个），比手机号好解决得多。

## 四、流程与时效

1. 后台提交 → 平台初审（约 1~2 个工作日）
2. 工信部短信核验（24h 内完成）
3. 管局审核（各省 1~20 个工作日不等，多数 1~2 周）
4. 通过后备案号会自动挂到小程序"关于"页 —— **提审时如果备案还没下来，先别提**，代码里 `docs/上线检查清单.md` 的备案项要等这个号

**总节奏建议**：今天提交备案 → 等管局期间照常发视频 → 备案下来再提审小程序 → 双通过即正式上线。
