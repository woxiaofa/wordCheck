# 小程序注册信息填写指南

> 适用于本项目（背单词 / 后续扩展为全科任务抽查）。
> 写这份文档的原因：注册时填的**名称、主体、类目**三件事，事后改的成本都远高于现在多花十分钟想一想。
> 文中规则均已核对微信官方客服文档与开放社区 2026 年现行口径，具体以 MP 后台实时提示为准。

---

## 〇、结论先行（4 条）

1. **个人主体不能升级成企业/个体工商户。** 微信官方口径："小程序不支持个人主体直接变更为企业主体认证"，只能重新注册一个新号、重新提交类目审核、用户重新授权，旧号的名称和历史访问记录无法继承。**所以"先个人跑着、赚钱了再升级"这条路不存在，只有"另起炉灶"。**
2. **名字建议一次取全科通用的。** 个人主体改名**每个自然年只有 2 次**，用完只能等明年（个人主体无法微信认证，不能靠认证重置次数）。改名后还要在 **7 日内变更备案**，否则可能被处置。
3. **搜索流量不用靠名字。** 名称不带"单词"会损失一部分搜索量，但可以在简介里写清楚（简介同样参与搜索匹配），代价远小于以后改名。
4. **全科能做，但 K12 学科培训是资质红线。** 语文/数学/英语"作业辅导、在线培训"需要教育资质，个人主体拿不到；定位成**记忆/复习/自查工具**风险显著更低。详见第五节。

## 一、先做主体决策（这比取名字重要）

### 1.1 两种主体的能力对比

| 能力 | 个人主体 | 个体工商户 / 企业 |
| --- | --- | --- |
| 注册成本 | 0，当天可用 | 个体户约几百元（多地线上可办，1–3 天） |
| **微信支付** | ❌ **无法开通** | ✅ 可开（需营业执照 + 对公账户） |
| 微信认证 | ❌ 不可认证 | ✅ 300 元/年 |
| 改名 | 每年 2 次，用完等明年 | 每年 2 次，用完可付费认证重置 |
| 改名后备案 | 7 日内必须变更 | 同 |
| 服务类目 | 工具/生活服务等窄范围 | 全类目（含教育、电商等，需对应资质） |
| 获取手机号 | ❌ | ✅ |
| UnionID 打通 | ❌ | ✅ |
| 流量主广告 | ❌（需企业认证） | ✅ |
| 投放广告 | ❌ | ✅ |

### 1.2 三条路，按你的情况选

**方案 A（推荐，如果你确定要做付费）**
现在暂停注册 → 先办**个体工商户营业执照**（多数地区全程网办、费用几百元以内，1–3 天下证）→ 用个体户主体注册小程序 → 名字一次取对 → 一路做到教练端付费，中间不用换号。
*理由：换号的成本（重新审核、用户重新授权、名字可能被占、搜索权重清零）远大于办个体户的成本。*

**方案 B（如果你要先把内测跑起来）**
用个人主体注册，现在就跑真机内测（不收钱、不需要支付，完全够用）→ 验证通过后再注册个体户新号。
*但要提前知道：*
- 新号要换名字，或个人号先改名把名字腾出来（改名一年 2 次，够用）
- 用户数据不继承，需要引导老用户迁移（好在目前是本地存储，本来就要迁到云端）
- 两个号并行一段时间再下线个人号

**方案 C（保守）**
只做免费工具，不做付费。个人主体够用，但教练端订阅、押金、付费词库全部做不了。

> **我的建议**：你前面已经明确规划了教练端付费、押金、付费词库，那**商业化的概率很高**。如果办个体户对你来说不是难事，走方案 A；如果暂时不想办，走方案 B 但**现在就把名字取成通用的**（第五节会说明为什么这对换号也有好处）。

## 二、命名规则（改名前必读，数字都是硬的）

| 规则 | 具体 |
| --- | --- |
| 长度 | 4–30 个字符，**1 个汉字 = 2 字符**（即 2–15 个汉字） |
| 简称 | 从名称中按顺序截取，4–10 字符（2–5 个汉字），展示在任务栏 |
| 唯一性 | 微信公众平台内唯一；**同一主体下可与自己的公众号同名**；不同主体不得与已存在的公众号/小程序同名 |
| 个人主体禁用 | 公司、集团、中心、官方、网、平台等企业性质字样 |
| 慎用（触发保护词审核） | 教育、培训、学院、学校——命中后需额外审核（约 7 个工作日），个人主体风险更高 |
| 改名次数 | 境内主体每自然年 **2 次**（1 月 1 日重置）；个人主体用完等明年，企业主体可付费认证重置 |
| 改名后 | **7 日内**到【账号设置 → 小程序备案 → 变更】提交变更备案 |
| 其他 | 审核通过后不可撤销；不得含连续 2 个以上特殊符号 |

**提交前务必在 MP 后台实时检测名称占用情况，并准备 2–3 个备选**（短词大概率已被占用）。

## 四、完整填写清单（可直接复制）

### 4.1 名称 / 简称

| 字段 | 填什么 |
| --- | --- |
| 小程序名称 | 每日抽查 |
| 小程序简称 | 每日抽查（2–5 汉字，从名称截取即可） |

### 4.2 简介（参与搜索匹配，务必写满）

**个人主体版（不提任何付费）：**

```
每天 10 分钟，背单词、记考点。看词回想意思，如实点"认识/想了很久/不认识"，
系统按遗忘曲线安排复习时间；学完自动进入抽查，答对的词 15 天后再见，
答错的 10 分钟就回来。家长老师可布置任务，看到真实掌握情况，而不是自评。
```

**企业/个体户版（可提任务与数据）：**

```
每天 10 分钟，背单词、记考点。系统按遗忘曲线排复习，学完自动抽查检验真实水平。
家长和老师可一键布置任务、查看学员掌握情况与周报；支持自建词表，拍照上传课本单词表。
```

### 4.3 服务类目（决定能调用哪些 API、能否过审）

**个人主体 —— 推荐：**

```
工具 → 效率工具
```

**理由**：个人主体可选类目很窄，"教育 → 在线教育"需要提供**个人教师资格证或与持证机构的合作证明**，拿不出来就会被驳回。背单词本质是记忆工具，选"工具-效率"最稳，且不影响卡片、发音、云开发等全部功能。

**企业/个体户主体（等做教练端付费时再改）：**

```
教育 → 在线教育（或 教育 → 教育信息服务）
工具 → 效率工具（可同时选两个）
```

> ⚠️ 类目不是越大越好：**实际功能超出所选类目范围**是审核驳回的高频原因。现在功能就是背单词工具，就选工具；等教练端上线再加教育类目。

### 4.4 头像

- 建议：纯色底 + 单一图形符号（如卡片 ✓、勾 ✓、喇叭）。品牌色沿用项目的蓝色 `#3ea6ff`。
- 不要：真人照片、学校/机构 logo、"微信"字样、二维码。
- 规格：PNG，512×512 以内，图形居中（微信会圆形裁切）。

### 4.5 服务范围 / 隐私

- **服务范围**：勾选"仅中国内地"（后续如涉及其他地区再扩）。
- **隐私协议**：必须配置，路径【设置 → 服务内容声明 → 用户隐私保护指引】。本项目实际只用到"用户主动选择的词书偏好"与学习记录，勾选" storage / 用户主动产生的学习数据"即可，**不要勾手机号、位置**（个人主体也拿不到，勾了反而与隐私指引不符被驳回）。

### 4.6 搜索关键词（如后台有【推广 → 搜索关键词】入口）

```
背单词,英语单词,中考单词,高考单词,四级单词,单词打卡,抽查,记忆,作业,错题
```

## 五、以后做"全科 + 家长老师发任务"：能做吗？

### 5.1 技术上：完全可以，而且成本不高

现在的数据是 `words`（word / phonetic / pos / def_cn / example_en / example_cn），要做全科只需两步抽象：

1. **把"词"抽象成"条目 item"**：加 `subject` 字段（english / chinese / math / …），条目内容从"单词+释义"扩展为"题干+答案+可选提示"。
2. **题型从"三种"扩展为"题型工厂"**：现在的选义 / 拼写 / 听写已经是按题型分发的（见 `shared/quiz.js` 的 `planTypes`），古诗填空、公式默写可以复用同一套"出题—作答—判分—回流 SRS"的骨架。

`utils/books.js` 的词书机制已经是可扩展雏形，将来"词书"变"科目-教材-单元"三级即可。

**建议：现在不要提前重构。** 理由是所有科目共用的那条 SRS 主链路还没被真实用户验证过，先拿英语跑通、确认留存能起来，再花两天抽象一次更划算。

### 5.2 合规上：这是真正的红线，不是技术问题

| 要做的事 | 风险 | 说明 |
| --- | --- | --- |
| 单词/古诗/公式的**记忆与自查工具** | 🟢 低 | 工具属性，名称与简介保持"工具"定位 |
| 家长给孩子布置**复习任务** | 🟡 中 | 家庭场景，属自用，风险可控 |
| 老师给学员布置**作业并收费** | 🟠 中高 | 接近"校外培训"，需教育类目资质，**个人主体不可能拿到** |
| K12 学科**在线培训 / 在线授课 / 辅导** | 🔴 高 | 需办学许可等资质，"双减"后审核极严，个人主体直接不可做 |

**三条具体建议：**

1. **定位永远写"工具"，不写"培训/辅导/课程"。** 名称、简介、页面文案、给审核员的说明都保持一致。产品做的是"记忆与自查"，不是"教学"。
2. **收费对象是教练/家长的能力，不是学科内容本身。** 收费点放在"布置任务、查看数据、管理多个学员"这些**效率功能**上，而不是"买语文课/数学课"。这既是之前商业模式文档里"配额制"的思路，也降低了合规风险。
3. **个人主体下不要做 UGC 分享。** 用户上传词表、教练自定义任务属于用户生成内容，个人主体审核更严，必须过 `msgSecCheck` 内容安全检测。内测期建议只做本地自用，等企业主体再开放分享。

### 5.3 换号时的名字衔接（如果走方案 B）

个人号占着的名字要先腾出来给新号：
1. 用个人号的 2 次改名机会，把它改成一个临时名（如"每日抽查旧版"）
2. 立刻（7 日内）提交变更备案
3. 旧名释放后（改名后旧名有保护期，同主体 2 天、其他主体约 30 天），用个体户新号注册同名
4. 新号过审后，在个人号内引导用户迁移，跑一段时间再注销个人号

> 这就是为什么**现在取通用名很重要**：通用名在你换号时同样适用，省掉一次改名和一次备案变更。

## 七、一句话总结

**个人主体现在就能跑，但它是"一次性"的——想收钱必须重开新号。所以：名字现在就取通用的（推荐「每日抽查」），类目选"工具-效率"，简介里把"背单词"写满；如果办个体户对你不难，最好现在就办了再注册，能省掉后面换号的一整套麻烦。**
