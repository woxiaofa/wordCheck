# 贴图话题 · 推广文案与配置手册

> 2026-10-19 整理。贴图话题 = 微信 2026 年新内容生态「贴图号」给小程序开的公域入口，
> 完全免费。用户在你的话题页发图文（晒打卡），内容进入微信公域推荐池
> （公众号/服务号消息盒子、搜一搜、位置页、话题聚合页），贴图可挂小程序链接，
> 陌生人点一下就直达你的小程序。

## 一、后台怎么填（创建前必读）

入口：mp 后台 → 基础功能 → 贴图话题 → 创建话题。

| 字段 | 要求 | 怎么填 |
|---|---|---|
| 话题名称 | **≤16 字，创建后不可修改** | 见下方候选，选好再填 |
| 背景图 | 宽高比最大 4:3 | 已生成 `assets/topic-bg.png`（1200×900），直接上传；想改内容跑 `scripts/gen_topic_bg.py` |
| 话题描述 | **≤40 字** | 见下方压缩版 |
| 推荐链接路径 | 只能是本小程序页面 | `pages/index/index`（获取方式：创建页问号有官方指引） |
| 推荐链接标题 | 与贴图内容相关，别人才愿意点 | 见下方文案 |
| 自动添加位置 | 可选 | 无门店可不开 |

## 二、话题名候选（≤16 字，先选后填，不可改）

1. **#我家娃的单词打卡**（推荐）—— 家长视角，晒娃动机最强，也最口语化
2. #两分钟搞定今日单词 —— 突出卖点，适合配合视频号口播
3. #小学英语单词打卡 —— 偏搜索友好（家长会搜这类词）
4. #娃的单词测验报告 —— 跟产品报告页强绑定

## 三、话题描述（后台限 40 字，压缩版二选一）

1. 晒娃练单词的日常：测验报告、成绩单、开口读单词的截图。每周精选 3 条置顶。
2. 真实记录娃的单词打卡：测验报告、成绩单、跟读截图。每周精选置顶，一起坚持。

**合规红线（个人主体更要守住）**：
- 不承诺效果（不能写"7 天记牢 500 词"）
- 不搞抽奖送实物（个人主体资质办不了，也别学星巴克那套"晒图抽奖"）
- 不诱导分享（不能"必须分享才能解锁"）
- 内容真实，后台对负面/摆拍内容有置顶+屏蔽两个管理动作

## 四、推荐链接标题（贴图里那张小程序卡片的文案）

1. 免费 · 给娃抽查单词，一天十个两分钟
2. 这份单词测验报告，2 分钟自动生成
3. 老师留的单词作业，用它抽查最省事
